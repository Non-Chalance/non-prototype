# non-prototype

An experimental questionnaire exploring observation, attention and participant behaviour.

This is an early prototype intended to collect questionnaire responses and interaction metadata, including dwell time, answer revisions and completion behaviour.

The questionnaire is part of a broader experiment investigating whether meaningful observations can be derived from both answers and the process used to arrive at them.

## Running

Open `index.html` in a web browser.

No installation is required.

## Data Collected

The prototype currently records:

- Participant Code
- Opt-in status
- Answers
- First answer selected
- Final answer submitted
- Number of answer changes
- Time spent per question
- Total completion time
- Completion status

## Data Not Collected

The prototype does not intentionally collect:

- GPS location
- Camera data
- Microphone data
- Contacts
- Browser history
- Device fingerprinting

## Status

Prototype 0.1

Current objective:

Determine whether behavioural metadata provides meaningful insight beyond questionnaire responses alone.
